# Synthetic examples

`report.example.json` and `report.example.md` use schema 0.2.0 and wholly synthetic GPU/path facts. They are generated from the topology test fixture through the actual collector transformation, privacy boundary, and exporters. They illustrate two inventory adapters and one active path matched to the second adapter. They are format examples, not measurements from a real machine.

Real smoke-check reports are kept only in ignored `artifacts/`. Never replace these examples with a machine dump.
